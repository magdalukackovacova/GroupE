# Nota quod sancto concilio non est detrahendum — Manuscript Visualisation

A digital humanities project visualising several manuscripts containing Johann Hildessen's treatise *Nota quod sancto concilio non est detrahendum*.

---

## About the Project

This repository contains tools and data for the comparative visualisation of manuscripts transmitting Johann Hildessen's treatise on the authority of church councils. The project aims to make the textual relationships, variants, and codicological features of these witnesses accessible through interactive digital interfaces.

### The Treatise

*Nota quod sancto concilio non est detrahendum* is a polemical work defending the legitimacy and authority of ecumenical councils. The treatise survives in multiple manuscript copies, whose relationships and textual histories this project seeks to illuminate.

---

## ANTIDOTE Group E

This project is developed by **Group E** of the ANTIDOTE initiative during a workshop in **Bratislava, 25–29 May 2026**.

**ANTIDOTE** is an international digital humanities project supported by the **Erasmus+ Programme** of the European Union. It brings together researchers and students to develop skills in digital methods for textual scholarship.
